# AMR 무선 관제 및 예지보전 시스템

> 엣지-클라우드 협동 구조의 자율주행 로봇(AMR) 관제 시스템.
> 로봇(엣지)은 명령 실행과 센서 송신을, PC(클라우드)가 판단·감시·제어·예지보전을 담당합니다.

**🚧 진행 중인 프로젝트입니다.** 유선 통신 → 무선 전환 → 안전로직 → 예지보전(감지·진단·대응)까지 완료했으며, 이후 확장을 진행 중입니다.

---

## 프로젝트 개요

반도체·제조 장비 SW의 관제 구조를 소형 AMR로 구현한 학습·포트폴리오 프로젝트입니다.
"AI 없이도 완벽히 동작하는 시스템"을 먼저 구축하고, 그 위에 예지보전을 얹는 순서로 진행했습니다.

| 구분 | 내용 |
|---|---|
| **엣지 (로봇)** | Arduino Uno + 4WD 스마트카 · 초음파/전류 센서 · 서보 · HC-06 블루투스 |
| **클라우드 (PC)** | C# WinForms 관제 GUI · Python 데이터 분석 |
| **통신** | 커스텀 바이너리 패킷 프로토콜 (XOR 체크섬) · 블루투스 무선 |
| **안전** | 하트비트 워치독 (통신 두절 시 자율 정지) |
| **예지보전** | 모터 전류(MCSA) 기반 이상 감지 → 유형 진단 → 자동 대응 |

---

## 주요 기능

### 실시간 관제
- PC에서 로봇 방향 제어 (전/후/좌/우/정지, 비상정지)
- 초음파 거리 · 모터 전류 실시간 수신 및 그래프 표시 (GDI+ 직접 렌더링)
- 수신 스레드 분리 + UI 스레드 마샬링(Invoke)으로 안정적 실시간 갱신

### 커스텀 패킷 프로토콜
```
[STX=0x02] [LEN] [CMD] [DATA...] [CHK] [ETX=0x03]
```
- CMD 대역 분리: `0x1_` 명령 / `0x2_` 센서 / `0x3_` 제어 / `0x4_` 예지보전 대응
- XOR 체크섬으로 무선 환경의 데이터 손상 탐지
- 조각나서 도착하는 시리얼 데이터를 상태 기반 조립기로 재조립

### 워치독 안전로직
- PC가 100ms마다 하트비트 전송
- 로봇이 일정 시간 미수신 시 **스스로 정지** (외부 비의존 자율 안전장치)
- 무선 환경에 맞춰 타임아웃·주기 튜닝으로 오작동 최소화

### 예지보전 (감지 → 진단 → 대응)
- ACS712 전류센서 통합, 드리프트 대응 동적 영점 보정
- Python으로 정상/부하/이물질 데이터 분석 → 유형별 고유 특징 규명

  | 상태 | 평균 | 표준편차 |
  |---|---|---|
  | 정상 | 8.07 | 2.70 |
  | 부하(무게) | 10.19 | 1.50 |
  | 이물질(마찰) | 14.36 | 2.28 |

- **이상 감지:** 이동평균 기반 실시간 판단 (직진/후진 구간)
- **유형 진단:** 평균 + 표준편차로 부하 이상 / 이물질·마찰 구분
- **자동 대응:** 부하는 경고 표시, 이물질 2초 지속 시 자동 정지 + 서보 좌우 경고

## 설계 원칙

1. **역할 분리** — 로봇은 실행, PC는 판단·예지보전
2. **유선 우선, 무선은 나중** — 검증된 토대 위에 확장
3. **단계적 검증** — 한 방향씩 검증하여 문제 원인 격리
4. **데이터 기반 의사결정** — 임계값 등을 실측 분석으로 도출
